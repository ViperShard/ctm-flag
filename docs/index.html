What it does

Shared call context, without leaving CTM

No spreadsheets, no Slack threads about call IDs. The notes live right next to the calls.

📌

Flag any call

A small pin on every call row. Click to add a note or question; the pin fills amber once flagged.

⚡

Real-time for everyone

Backed by Firebase Firestore. Add or remove a flag and teammates see it within about a second — no refresh.

🗂️

Flagged Calls panel

A slide-down list of every flagged call: the note, who flagged it, when, and a jump-to-call link.

🎯

Go to call + highlight

Click “Go to call” and the page scrolls to the row and flashes it so it’s easy to spot.

🧩

Feels native

Injected inline and styled to match CTM. No popups, no new tabs, no clutter on the page.

🛡️

Fails safe

If Firebase is unreachable, the CTM page is never broken — the tool just tells you to finish setup.

How it works

From install to flagging in minutes

One person sets up a free Firebase database; everyone else just installs the extension.

1

Create a free DB

Spin up a free Firebase Firestore project and paste 3 config values into the extension.

2

Build & load

npm run build, then load the dist/ folder via your browser’s extensions page.

3

Open CTM

Pins appear on every call and a “Flagged Calls” button lands in the toolbar.

4

Flag & share

Add a note. Your whole team sees it live — and you see theirs.

Setup

Get it running

Works in Chrome, Edge, Brave, and other Chromium browsers. Full steps are in the README.

1 · Build the extension

# clone, then in the project folder:
npm install
# add your Firebase keys to src/firebase.js, then:
npm run build
# → produces the dist/ folder

The free Firebase “Spark” plan is plenty — no credit card needed. The README walks through creating the database and finding the 3 config values.

2 · Load it in your browser

  1. Open chrome://extensions (or edge://extensions).
  2. Turn on Developer mode.
  3. Click Load unpacked and pick the dist/ folder.
  4. Open CTM — the 📌 buttons appear on every call.
